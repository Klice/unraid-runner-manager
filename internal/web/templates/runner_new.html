Where to get the token

  1. Open the repository on GitHub.
  2. Settings → Actions → Runners → New self-hosted runner.
  3. Copy the value after --token. It expires in one hour.

Where to get the token

  1. Open the project on GitLab.
  2. Settings → CI/CD → Runners → New project runner.
  3. Pick the tags and description there. Leave Lock to current projects off if other projects should use it too.
  4. Create it and copy the glrt- token from the next page. Skip the install and register steps.
